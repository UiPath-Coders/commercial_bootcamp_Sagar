# Lab 5 reference solutions (facilitators)

`Invoice_Approval_Agent_Reference/` is a complete, runnable, tested version of the coded agent
participants build under `../agent/` in Lab 5. Open its `README.md` for what it is, how to run the
tests offline, and what could not be verified without a tenant.

Participants do not need this folder; their Claude Code session works in `lab5-coded-agent/` and
creates the agent in `agent/`.
