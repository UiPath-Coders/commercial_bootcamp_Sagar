# Agent Project Location

Claude Code creates the Lab 5 UiPath coded-agent project in its own folder
`agent/Invoice_Approval_Agent_<user_name>/` during step 4 of the lab. Do not initialize another Git repository here.

## What Claude Code generates here

Using the `uipath-agents` skill it scaffolds a LangGraph project with `uip codedagent new`, implements
the agent, and runs `uip codedagent init`. Expect roughly:

```text
agent/
  Invoice_Approval_Agent_<user_name>/   # the project's own folder; the scaffold runs inside it
    main.py              # LangGraph graph: read record -> four deterministic gates -> (LLM narrative, gate 4 only) -> write back
    langgraph.json       # {"graphs": {"agent": "./main.py:graph"}}  -> the entrypoint is named "agent"
    pyproject.toml       # uipath-langchain dependency, no [build-system]
    uv.lock, .venv/      # created by uv
    entry-points.json    # generated by `uip codedagent init` from the typed input/output models
    uipath.json, bindings.json, project.uiproj, agent.mermaid, CLAUDE.md, AGENTS.md, .agent/   # generated
    evaluations/
      evaluators/json-similarity.json
      eval-sets/smoke-test.json     # the six AP-TRAIN cases adapted to the agent's input schema
```

The agent reads one `AP_Invoice_<user_name>` record by Id through the UiPath Python SDK (tenant scope,
no folder), evaluates gates 1–4 in order before any LLM call, and writes `ApprovalEvidenceState`,
`MissingApprovalFields`, `AgentRecommendation`, `ApprovalPackageJson`, `AgentProcessedAt`, and
`InvoiceLifecycleState` back to the same record. No `ApprovalStatus` entity, no `Status` field.
